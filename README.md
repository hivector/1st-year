# 1st Year

An archive of academic resources for first-year students at SATI, Vidisha.

This repository contains the syllabus and previous year question papers, organised by semester and subject.

### Contents

- `Syllabus` — Semester-wise syllabus PDFs.
- `PYQs` — Previous year question papers.

### Built with

HTML · CSS · JavaScript

### Run locally

```bash
git clone https://github.com/hivector/1st-year.git
cd 1st-year
```

Open `index.html` in your browser.
